# Architecture Analyzer + Health Engine v1.0

## Purpose
Convert normalized project facts into evidence-backed engineering findings.

## Findings are not commands
A recommendation such as "resolve missing dependencies" is an analysis result.
It does not authorize UPA to change the project.

## Score
The initial score is a governance-oriented signal, not a claim of AAA quality.
It measures known structural risk from the available ProjectModel.

## Next
The next layer should be a Planning/Intent Engine that turns findings and user intent
into an explicit plan, with preconditions, confidence, dependencies, preview and approval gates.
