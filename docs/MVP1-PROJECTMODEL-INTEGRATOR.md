# ProjectModel Integrator v1.0

The integrator establishes the single-model boundary between scanners and future
UPA intelligence/planning systems.

## Rules
1. Scanner outputs remain provenance-aware.
2. Facts are separated from future inference.
3. Counts are normalized and validated.
4. Model schema is versioned.
5. Snapshot provenance is explicit.
6. This layer has no mutation capability.
