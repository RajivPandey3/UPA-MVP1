- Do NOT modify V1.0 core.

Required test coverage:

1. EMIT
   Preserve existing tests.
   Confirm:
   - valid request reaches the endpoint successfully
   - missing required fields produce 400
   - 409 exception mappings remain represented by TrustErrorResponse
     if existing test infrastructure can exercise them without changing core behavior
   Do not manufacture new core exceptions just for testing.

2. VERIFY
   Add/confirm HTTP contract assertions for:
   - POST /v1/trust/verify
   - valid-shaped request reaches the boundary
   - current result is HTTP 501
   - response JSON contains:
         code = TRUST_VERIFY_NOT_IMPLEMENTED
         message
   - missing required fields produce 400

3. INSPECT
   Add/confirm HTTP contract assertions for:
   - GET /v1/trust/{id}
   - identifier is accepted
   - current result is HTTP 501

         code = TRUST_INSPECT_NOT_IMPLEMENTED
         message

4. JSON contract
   Where response JSON is asserted, verify snake_case keys:
       code
       message
   Do not introduce a global serializer policy.

5. Test isolation
   Tests must remain API-layer tests.
   Do not modify V1.0 tests to support this task.
